# Roadmap do Sistema

Este arquivo guarda a evolucao planejada do sistema para irmos marcando o que foi concluido ao longo do tempo.

Legenda:
- `[ ]` pendente
- `[x]` concluido

## Fase 1 - Base forte

### Permissoes e seguranca
- [ ] Revisar todas as permissoes do modulo igreja
- [ ] Revisar todas as permissoes do modulo ministerio
- [ ] Definir claramente quem pode ver, criar, editar, excluir e exportar em cada area
- [ ] Revisar regras de acesso dos relatorios
- [ ] Revisar regras de acesso dos cadastros da igreja

### Auditoria basica

- [ ] Registrar quem criou, editou e excluiu visitantes
- [ ] Registrar quem criou, editou e excluiu novos convertidos
- [ ] Registrar quem alterou permissoes importantes

### Validacao e consistencia de dados
- [ ] Melhorar validacoes dos formularios de visitantes
- [ ] Melhorar validacoes dos formularios de novos convertidos
- [ ] Revisar consistencia entre app, site e banco

### UX e operacao
